# Scorify - Native Android Application

Scorify is a native Android application built for real-time sports score tracking, match statistics, and offline data persistence.

## 🛠 Tech Stack & Tools
- **Languages:** Java, Kotlin
- **Database:** SQLite (Local Data Storage & Caching)
- **IDE:** Android Studio
- **Architecture:** Clean Architecture / MVVM concepts

## ✨ Key Features
- Live score tracking and detailed match updates.
- Local database integration using SQLite for offline access.
- Custom Adapters & RecyclerView for dynamic data lists.
- Clean UI/UX designed with Android XML.
